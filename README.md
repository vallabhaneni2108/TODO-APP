# TODO App

A simple command-line TODO application built with Python.

## Features
- Add tasks
- View tasks
- Delete tasks
- Mark tasks as completed
- update tasks 
- Store tasks in JSON format

## Technologies Used
- Python
- JSON

## How to Run

1. Clone the repository:
   git clone https://github.com/vallabhaneni2108/TODO-APP.git

2. Open the project folder.

3. Run:
   python main.py
